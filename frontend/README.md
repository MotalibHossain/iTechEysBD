# iTechEys — Frontend

Next.js 16 frontend for the iTechEys blog. Bilingual (Bangla + English), Tailwind CSS 4, shadcn/ui.

## Setup

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Dev server |
| `npm run build` | Production build |
| `npm run start` | Serve production build |
| `npm run lint` | Lint |
